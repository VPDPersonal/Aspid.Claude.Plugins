# Aspid.Claude.Plugins (archived)

[Русская версия](README_RU.md)

This marketplace is no longer maintained. Aspid packages now ship their [Agent Skills](https://agentskills.io) in their
own repositories, installable into Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot and other agents:

```sh
npx skills add VPDPersonal/Aspid.FastTools
```

If you added this marketplace, remove it with `/plugin marketplace remove aspid-claude-plugins`.
