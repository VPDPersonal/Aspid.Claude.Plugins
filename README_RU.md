# Aspid.Claude.Plugins (архив)

[English version](README.md)

Этот маркетплейс больше не поддерживается. Пакеты Aspid теперь поставляют свои [Agent Skills](https://agentskills.io)
в собственных репозиториях; они устанавливаются в Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot и другие агенты:

```sh
npx skills add VPDPersonal/Aspid.FastTools
```

Если вы добавляли этот маркетплейс, удалите его командой `/plugin marketplace remove aspid-claude-plugins`.
